# 业务分类框架（SG-CIM4.5 一二级主题域）

- 来源：《统一数据模型(SG-CIM4.5)概念模型设计说明书（暂行）》（国家电网有限公司，2020-01）
- **权威源声明：`sc01_governance.business_domains` 表是业务分类的唯一权威源**（2026-08-14 起；2026-09-14 库名由 `marketing_governance` 迁移，仿真档为 `fz01_governance`）。本文档仅为阅读参考，如与库表不一致以库表为准；分类的新增/调整只许改库表（直接 SQL 维护；deshu4 时代的 `_sgcim_domain_ingest.py` 未随仓库迁移），文档随后同步。
- 固化位置：`sc01_governance.business_domains` 表（10 个一级 + 89 个二级，2026-08-14 入库）
- 用途：**为数据明细表、数据资源表标注"所属业务"标签的分类依据**。标签取值约定：一级取 `domain_code`（如 `Cst`），二级取 `domain_code`（如 `Cst03`）；一张表建议标 1 个一级 + 1~2 个二级。
- **三级预留**（2026-08-14）：`level` 已扩展为 1/2/3（CHECK 约束），三级编码约定为"二级编码+两位序号"（如 `Cst0301`），`parent_code` 指向二级编码；当前无三级数据，待 SG-CIM 各主题域分册提供实体级分类后直接入库。
- 口径说明：一级定义取自说明书表 1；二级名称及实体/属性数量取自图 2"元素周期表"（图中未量化的 9 个二级域计数字段为 NULL）；模型总量：10 个域、实体 4361 个、属性 79135 个。

## 三、打标实施结果（2026-08-14 已落库）

已对 4 张资源表完成行级打标（统一 3 列 `domain_l1`/`domain_l2`/`domain_l3`，三级置空预留；取值均可回溯到 `business_domains.domain_code`）。标定脚本 `_biz_tagging.py`（幂等，可重跑）。

**决策口径（用户确认）**：设备/站点/管线类维表归 `Cst03 计量`（营销视角）；管理单位归 `Cst01 客户公共包`；账务表拆分——计费卡/退补单/合同账户归 `Cst02 客户`，台账类归 `Cst04 付费`。
