# 正式文档通用格式规范（三类文档共用）

## 文档头（必须，置于标题前）

```
文档编号：KJGL-<类型码>-<年份>-<序号>     （类型码：ZS=综述，XQ=需求清单，MH=方向谋划）
密级：内部
编制单位：国网浙江省电力有限公司信息通信分公司 能源大数据服务中心
编制日期：YYYY年M月
版本：V1.0
```

## 章节编号体系（强制）

- 一级：`一、` `二、` `三、`……
- 二级：`（一）` `（二）`……
- 三级：`1.` `2.`……
- 四级：`（1）` `（2）`……
- 禁止使用 Markdown 的 `#`/`##` 以外层级表达章节；标题用 `#`（文档标题）与 `##`（一级章），二级及以下一律用文字编号，不用 `###`。

## 图表编号

- `表1`、`表2`……（表题在表上方）；`图1`、`图2`……（图题在图下方）。
- 表格一律 Markdown 标准表格，列数 ≤7，超出则拆表。

## 引用纪律（强制）

- 正文引用一律用方括号编号 `[1]` `[2]`，编号对应文末《参考文献》。
- 参考文献条目格式：`[n] 作者. 标题[文献类型]. 出处, 年份. 获取标识.` 其中文献类型：J=期刊 C=会议 EB=电子预印本(arxiv) S=标准；获取标识：arXiv:xxxx.xxxxx 或 DOI 或 IEEE 文献号。
- **每条引用必须来自检索结果库**（skills/research-planning/results/*.json），禁止凭记忆编造文献；拿不准的一律不写。
- 正文中同一文献多次引用用同一编号。

## 语言风格

- 书面公文语体：用"本项目/公司/亟需/支撑/面向"，不用"我们/我觉得/很/非常"等口语。
- 数据、指标须注明来源或出处编号；无量纲口号式表述（"国际领先"）须有对标依据。

## 版本记录（文档末尾，必须）

```
附：版本记录
| 版本 | 日期 | 编制/修订说明 | 审核 |
| V1.0 | YYYY-MM-DD | 初稿 | （待审） |
```
