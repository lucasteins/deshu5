# 《研究方向谋划》格式模板（类型码 MH）

## 结构（固定）

```
<文档头（见通用规范）>
# 下阶段研究方向谋划报告（<年份区间>）
## 一、现状与基础
（一）在研/待验收/已验收项目梯队     ← 表1：项目编号|名称|阶段|经费|承担/合作单位
（二）规划需求储备情况
（三）平台与数据资产
## 二、形势分析
（一）国际技术态势                   ← 判断须有引用[n]
（二）政策与行业背景
（三）公司战略契合点
## 三、总体思路
主线划分（建议 4–6 条主线）及各主线"延续/深化/新拓"逻辑
## 四、方向矩阵                      ← 表2：主线|方向|类型(延续/深化/新拓)|对应需求/项目|优先级
## 五、优先级与立项建议               ← P0/P1/P2/P3 分级，每级说明理由
## 六、路线图                         ← 按半年度列里程碑（YYYY H1/H2），表3
## 七、合作与转化布局
（一）高校/机构合作布局
（二）标准与成果转化通道
## 八、风险与保障措施                 ← 技术/进度/依赖/政策四类风险逐条+对策
## 参考文献
## 附：版本记录
```

## 质量要求

- 方向矩阵必须覆盖全部在研项目与规划需求，不允许出现"无归属"项目。
- 优先级分级须给出可核实的理由（窗口期/转化路径/依赖关系），禁止只写"重要"。
- 路线图里程碑须可考核（有产出物名称）。
- 全文 5000–10000 字。
