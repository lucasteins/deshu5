# 《前沿综述》格式模板（类型码 ZS）

## 结构（章节标题与顺序固定）

```
<文档头（见通用规范）>
# <主题领域>前沿技术综述（<年份>）
## 一、编制说明
（一）编制目的与用途
（二）综述范围与主题划分
（三）数据来源与检索方法    ← 写明：arxiv API（主题数/篇数/最新日期）、IEEE Xplore（经浙大CARSI机构访问，检索式与条数）、nature.com（同上）；注明检索日期
（四）术语与缩略语          ← 表1
## 二、总体态势判断
按"国际领先/并跑/跟随"三档给出公司在各主题的相对位置，并说明依据[引用]
## 三、分主题前沿综述       ← 每个主题一节，节内固定四小节：
（一）国际前沿动态          ← 每条代表性工作须带引用[n]，注明出处与年份
（二）国内研究现状
（三）与公司在研项目及规划需求的对照   ← 对照 kjgl 项目库/需求清单的具体条目
（四）差距分析与机会判断
（主题一：……）
（主题二：……）……
## 四、主题间协同分析
## 五、结论与建议
## 参考文献
## 附：版本记录
```

## 质量要求

- 每个主题的代表性国际工作 5–10 项，须覆盖近 2 年；高被引经典（被引>100）可不受年份限制。
- "对照"小节必须落到 kjgl 具体项目编号或需求名称，禁止泛泛而谈。
- 全文 6000–12000 字；引用文献 30 条以上。
